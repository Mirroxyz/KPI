# Міська бібліотека — модель даних

## Обраний домен

Цей проєкт описує дані міської бібліотеки: каталог книжок, авторів і тематичних категорій, фізичні примірники, читачів, видачі та бронювання. Модель підтримує ситуацію, коли одна книжка має кілька фізичних примірників, а читач може послідовно користуватися різними примірниками.

Домен обрано тому, що він містить різні типи зв'язків і добре демонструє нормалізацію:

- `BOOK` — бібліографічний опис видання, а `BOOK_COPY` — конкретний фізичний примірник;
- книжка може мати кількох авторів і належати до кількох категорій;
- видача пов'язує читача з конкретним примірником у часі;
- бронювання ставиться на книжку, а не на випадковий примірник.

## Використання AI

AI використовувався для підготовки чернеток і перевірки моделі. Фінальні рішення, виправлення та відповідність вимогам `spec.md` перевірені й зафіксовані автором; повний журнал взаємодії збережено в [prompt-history.md](./prompt-history.md).

Фізичну схему БД, SQL DDL та ORM у цій роботі навмисно не створено.
